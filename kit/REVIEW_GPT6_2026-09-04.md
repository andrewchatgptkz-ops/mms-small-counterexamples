## Главная новая идея: индексировать не по n, а по цикломатическому рангу
Наблюдение GPT-6: у всех наших графов m − 2n + 1 = 4 (призма: 9 рёбер − 6 вершин + 1; подразделения ранг не меняют; K3,3 тоже 4). Рост n лишь удлиняет «провода» той же схемы; шаг 7→8 при 19 предметах сохраняет ранг 4 — мы растягивали старую конструкцию, а не строили новую. Следующий уровень — ранг 5: m = 2n + 4, каркас — кубический граф на 8 узловых вершинах. **Первый полигон — 7×18, а не 8×20**: задача меньше, сплит 3+4 уже успешный, каркас впервые сложнее. Это уточняет наш P13: те же пять кубических графов на 8 вершинах, но сначала при n=7 (8 узлов + 6 подразделений = 14 вершин, m = 12 + 6 = 18). Паритеты подразделений задаются двухцветной разметкой каркаса — перечисление дёшево.

## Остальные предложения (ранжировано Claude по цене/ценности)
- **Оптимизировать отношение напрямую, не только B = T−1.** Для улучшения 26/27 при B = T−d достаточно T < 27d: d=2 → любое T ≤ 53 (51/53 < 26/27), d=3 → T ≤ 80. Robust-CEGIS: нормировать суммы к 1, вещественные R, C, минимизировать достижимое ρ, оракул — max-min, cut — дизъюнкция, потом масштабирование в целые. Мы отмечали d=2 в списке, но не использовали; принять как основной режим следующего поиска.
- **5×12 — самая выгодная малая точная задача**: контрпример даст f(5)=11 ровно. Дёшево, чисто. Запустить параллельно.
- **Сертификат глубины 2** (ветвление по 2–3 предметам, 4–8 листьев, в каждом свой вектор весов; максимизировать не только разрыв, но и запас сертификата). Наш tree.py уже строит деревья произвольной глубины по LP; для инстансов с двумя «режимами выживания» (строчный/столбцовый) — естественно.
- **Комбинаторное препятствие раньше чисел**: SAT ищет два семейства минимальных выигрышных наборов без совместной (a+b)-упаковки, затем LP реализует их положительными весами. Выводит за пределы решётки; следующий шаг — три типа агентов (трёхмерный тензор инцидентности; Garg–Shahkar: 4/5 для двух типов, 16/21 для трёх). Спекулятивно, но это единственное предложение, способное дать «новую комбинаторную причину», а не ещё одну точку.
- **Gadget с граничной сигнатурой** → поиск цикла в пространстве сигнатур (7→9 возвращает сигнатуру) → периодическая бесконечная конструкция. Правильная теоретическая рамка для «теоремы о семействе»; работа для GPT-6 как теоретика, не как счётчика.
- **Gap(3,11)** — сначала упаковать архив Gap(3,10) в проверяемый пакет; для m=11 искать не точный gap, а отношение ниже 26/27.
- **Публикация**: препринт сейчас, не ждать n=8; флагман α ≤ 26/27, рядом f(4)=10, серия, сертификаты; ярусы раздельно; проверить приоритет через цитирующие списки FST/Hummel/Hsu/Garg–Shahkar и «коротко у специалистов».
